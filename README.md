# 이정민 포트폴리오

현장의 불편을 작동하는 도구로 만드는 기획자 이정민의 포트폴리오 웹페이지입니다.

## 보는 방법

`index.html` 한 파일로 동작합니다. GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포하면 바로 열립니다.

- 마우스 휠, 방향키(↑↓), 스페이스바로 한 장씩 넘깁니다.
- 왼쪽 목차를 누르면 해당 장으로 이동합니다.

## 구성 (11장)

| 순서 | 장 |
|---|---|
| 1 | 소개 |
| 2 | 한눈에 보기 |
| 3 | 01 MD Decision Lab (대표 프로젝트) |
| 4–6 | AI를 믿을 수 있게 설계한다: 02 AI Newsroom OS · 03 CASAMIA AI 커머스 · 04 Weversshop |
| 7–8 | 사람이 머물고 움직이게 만든다: 05 SpookMate · 06 스터디카페 |
| 9 | 기타 작업: 도서 탐색 페이지 · SpookMate 펫캠 · AI 숏폼 영상 |
| 10 | 역할과 도구 |
| 11 | 감사합니다 · 연락처 |

## 아직 채울 자리

- 프로젝트 화면 캡처 6개, 기타 작업 썸네일 3개 (가로 1600 × 세로 1000px 권장)
- 프로젝트별 발표자료 (PDF 또는 PPT)
- AI 숏폼 영상: YouTube 주소, 사용한 AI 도구
- MD 경력 연수, 전화번호
